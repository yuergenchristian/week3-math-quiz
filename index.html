FOR THE TEACHER

Teacher controls

Each student has 30 fixed questions with permanent IDs. The starting order is shuffled once per session and saved on this device.

Guided shuffle starts Mandala with simpler subtraction, Salsa with multiplication, and Fitri with a balanced mix. Questions are still shuffled within those groups.

Select a local audio file, or place your permitted music.mp3 at assets/music.mp3. Music plays only when you press the music button. Choosing a local file does not upload it anywhere.

Mark paper answers privately. Enter each child's attempted questions and correct answers. No answers are collected on the public quiz screen.

The default team goal, 23 correct, is above 75% of an initial 30-question benchmark (10 per child). Extra correctly answered questions can help the total. The 5-correct minimum ensures everyone participates; you can adjust either rule.

  1. Before class: print one 30-answer sheet per student. Choose music if you want it, and check that all questions are readable.
  2. Start: click the timer display. It counts down from 15 minutes. Click again to pause.
  3. Advance independently: click each student's right arrow when they finish. Left arrow returns to a previous question.
  4. On paper: write the permanent question ID (e.g. F-014) and the numeric answer. Scratch calculations go on separate blank paper.
  5. After time: check answers using your separate, private teacher key, then enter attempted and correct counts in the Team score tab.
  6. Future sessions: use New shuffled session to reshuffle all 30 questions per student. This does not generate new arithmetic problems.

Keyboard shortcuts (when this dialog is closed): 1, 2, 3 next for red/green/blue; Shift + the number for previous; Space start/pause; F fullscreen; Esc leave fullscreen.

This website has no backend and sends no scores online. Session preferences and teacher-entered scores are saved in this browser only. The public site's questions contain no answer keys; keep teacher PDFs off GitHub.
